# Grounded Growth Data Package

This package is the repository seed and AI handoff for the self-hosted Grounded Growth application.

## Start here
- `AGENTS.md` — binding instructions for coding agents
- `docs/PROJECT_HANDOFF.md` — product background, doctrine, architecture, and milestones
- `HANDOFF_PROMPT.md` — ready-to-paste Work/Codex prompt
- `MANIFEST.tsv` — file inventory and sizes

## Canonical data
- `data/curriculum/` — 383-competency pluralist curriculum
- `data/model/` — 37 levers, orientations, archetypes, mappings, and QA
- `data/assessment/` — assessment v1.1 and runnable HTML
- `data/notion/` — initial baseline imports and final Notion export

## Provenance
`legacy/` contains the original 876-task list, original JS, prior reduced curriculum, and optimized research-note PDFs. These are useful for design archaeology, but canonical structured data takes precedence.

## Repository safety
The source PDFs are user-provided research/design notes. This package does not assign a license to them. Review repository visibility and licensing before broad redistribution.
