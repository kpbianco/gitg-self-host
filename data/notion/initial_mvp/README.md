## Ranking formula used

Each task inherits one or more lever weights that sum to 1.0. Its static initial priority is:

`Task Priority = sum(Task Lever Weight × Lever Need Score)`

The baseline mastery and confidence displayed on each task are the corresponding weighted averages of its lever values.

This V1 does not dynamically update when scores change.
