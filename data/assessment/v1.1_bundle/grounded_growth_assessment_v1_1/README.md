# Grounded Growth Assessment v1.1

## Run it

Open `take_assessment_v1_1.html` in a current browser. It is standalone and requires no server.

## Core structure

- 12 orientation items: two for each non-evaluative orientation.
- 37 direct capability items: one for each developmental lever.
- 1 response-quality item.
- Up to eight adaptive capability clarifiers.
- Up to two orientation tie-breakers when the profile is flat.

## v1.1 cursory fixes

1. **Question timing fixed.** Selecting an answer no longer rerenders the question or resets the clock. Timing is captured when the user presses Next or Back.
2. **Speed penalty softened.** Fast completion modestly lowers evidence confidence; it cannot erase the score.
3. **Orientation wording sharpened.** Connection and stewardship now use explicit behavioral tradeoffs and stewardship includes systems, commitments, and resources—not only caretaking.
4. **Archetype naming corrected.** `The Architect` is now `The Systems Steward` so it is not confused with the MBTI nickname for INTJ.
5. **Archetype scoring improved.** It combines absolute orientation expression with relative distinctiveness and reports pair confidence.
6. **Score presentation corrected.** Results display raw self-report, calibrated estimate, and confidence separately.
7. **Keyboard support added.** Use 1–5, N, Enter, and Left Arrow.

## Important interpretation

- Orientation is preference, not skill.
- Archetype is a narrative mixture, not a diagnosis or MBTI replacement.
- Raw self-report is what the answers directly imply.
- Calibrated estimate is conservative until repeated evidence accumulates.
- Confidence is evidence strength, not a second judgment of ability.
- Task completion alone still does not update mastery; rubric-scored evidence is required.

## Compatibility

The v1.1 decoder accepts both `GGA1...` and `GGA11...` share codes. New results emit `GGA11...`.
