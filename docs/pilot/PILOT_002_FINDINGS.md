## Static Notion user test
The user selected a friendship-maintenance competency and completed a Guided Practice page. The reflection identified a real tension between transactional/ROI-oriented friendship expectations, reciprocity, initiation, acceptance, and deeper friendship.

User ratings:
- Comprehension: 4/5
- Selection: 2/5
- Activation: 2.5/5
- Actionability: 3/5
- Reflection value: 3/5
- Evidence clarity: 2/5
- Navigation: 3/5
- Administrative burden: 4/5
- Continuity: 3/5
- Credibility: 3/5

Qualitative findings:
- A user unfamiliar with Notion would need a primer.
- The dashboard felt cluttered and architecturally exposed.
- Broad competency prompts allowed vague or easily spoofed evidence.
- The bullet-based recap felt informal and unprofessional.
- The system required the user to design the intervention.
- The underlying recommendation remained plausible and reflection was useful.

## Product conclusion
This is a delivery-layer failure, not an ontology failure. Freeze the Notion consumer UX. Build a guided self-hosted app and introduce Practice Protocols before dynamic scoring.
