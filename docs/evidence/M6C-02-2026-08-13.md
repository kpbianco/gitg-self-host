## Implemented contract

The pure builder defines exactly five identity sections (`mission`,
`principles`, `anti_goals`, `twelve_month_direction`, `priority_stack`) and
four audit prompts (`current_truth`, `autopilot_pattern`,
`misalignment_or_fragmentation`, `deliberate_next_step`). It preserves
explicit unknown, not-applicable, deferred, and provided states; provided
scalar text is 1–500 characters and provided ordered lists contain one to five
unique nonblank items of at most 160 characters each.

Canonical compact UTF-8 JSON includes only contract/scope, assessment-epoch
stable ID, and the nine private state/value entries. SHA-256 is deterministic
for mapping-order-equivalent input, while authored list order remains
meaningful. The 64 KiB resource bound admits the maximum legal UTF-8 payload,
including worst-case JSON escaping. Invalid Unicode fails with an actionable
contract diagnostic. No automated text analysis, normalization, inference, diagnostic,
alignment, autopilot, personality, virtue, or worth score exists.

`PersonalOSRevision` is scoped, immutable, and append-only for one
authenticated owner and immutable assessment epoch. Changed input appends the
next contiguous revision; unchanged input returns the existing latest row.
Existing-row save, queryset update, bulk-update, bulk-create, instance delete,
and queryset delete fail. Foreign-key cascades preserve the existing account
and assessment lifecycle rather than introducing a deletion policy. Concurrent
SQLite writers either produce a contiguous unique result or an explicit
`retryable=True` conflict, with no partial row.

Independent system-risk review found that readiness messages were sanitized
but retained Django validation exceptions as chained causes. A traceback or
exception logger could therefore reveal a malformed private authored value.
The service and management-command boundaries now suppress those private-
bearing causes after replacing them with the bounded readiness diagnostic. A
behavioral regression corrupts one synthetic private value and verifies the
complete formatted exception chains from both public readiness interfaces do
not contain it.
