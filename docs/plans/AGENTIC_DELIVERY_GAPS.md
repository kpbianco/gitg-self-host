# Agentic delivery gaps

## Closed by this harness

- Product-data repository profile and project-specific skill.
- Exact active governance contract and current state.
- Cumulative local verification using the repository's actual Make/readiness
  commands plus migration and manifest checks.
- One-command, resumable contract generation, implementation, risk audit, CI
  repair, and draft-PR publication.
- Human-review target policy, specialist gate, and stable report-derived
  authoring cohorts.
- Web-search tool enabled for source discovery without shell network access.

## Immediate blockers

- ER-M6A-003 required specialist roles are incomplete.
- RG-M6A-002 remains open.
- M6C factor definitions and formula are not yet accepted/implemented.
- Phase B representative competencies are not yet selected.

## Deterministic gaps

- Context and Personal OS models, migrations, fixtures, readiness, and browser
  paths.
- Context-aware ranking and useful alternatives with no hidden defaults.
- Representative and full canonical package coverage.
- Source completeness and claim-level citation freshness.
- Whole-library scoring disposition and direction-complete fixtures.
- Upgrade/rollback, retention, and multi-version backup/restore drills.
- Automated semantic review cannot prove content quality; human review remains.

## Human/specialist gaps

- Measurement architecture, accessibility, privacy, and safety acceptance.
- Per-package cultural, disability, legal, clinical, organizational, or other
  specialist review when required.
- Multi-cycle recommendation fit, burden, abandonment, accessibility, safety,
  and bias review.
- Any production score cohort activation.

## Evaluation priorities

Track generic-content rejection, source/review gaps per cohort, first-pass CI,
repair success, owner rework, reverts, escaped doctrine/scoring regressions,
packages accepted per review hour, and user burden/fit outcomes.
